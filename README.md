# 校园应急与数字展陈终端

基于 HX4S20 / EG4S20BG256 FPGA 的校园展陈与应急提示项目，通过 HDMI_B 同时输出画面和声音。

## 功能

- TF 卡读取原版 PPT 导出的图片，保持比例显示，自动轮播与转场。
- 透明叠加年月日、星期、时间与滚动文明标语；板上按键手动校时。
- 循环背景音乐，按需显示音频波形、频谱及十进制参数面板。
- 应急模式显示左向撤离箭头和“大家请有序撤离”，播放循环警报与语音。警报资源内置于 FPGA。
- 波形采用 24 kHz 显示采样、352 个横向点、双缓冲和相邻采样点连线。

## 下载

本项目的背景音乐使用 Git LFS。安装 Git 和 Git LFS 后执行：

```powershell
git lfs install
git clone <本仓库地址>
cd <仓库目录>
git lfs pull
```

GitHub 的普通源码 ZIP 下载可能只包含音频的 LFS 指针。请用上述方式获取完整音频。

## 工程编译

使用安路 TD 6.2.1 SP1 和 Python 3。在工程根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .uild.ps1
```

脚本先更新工程与资源路径，再编译。若 TD 或 Python 未在默认位置安装，请配置 PATH 或修改 build.ps1 中的软件位置。顶层为 top，器件为 EG4S20BG256。编译输出位于 build，BIT 文件用于 JTAG 下载；不写入 TF 卡。

## TF 卡资源

将 media/MEDIA 文件夹整体复制到 FAT32 TF 卡根目录，保留目录结构。精简资源包含默认原稿相册的 25 张 BMP 及背景音乐。原稿中待修订的 5 页未加入；其他相册与测试图片不包含在此精简包中。

支持未压缩 24 位 BMP（最大 1280×720）及 48 kHz、16 位双声道 WAV。HDMI 输出为 640×480。

## 板上操作

- SW2：显示或隐藏音频可视化；SW3：显示或隐藏参数面板。
- 参数面板关闭时，KEY1/KEY2 切换图片，KEY3 暂停或继续，KEY4 切换转场。
- 参数面板打开时，KEY4 切换选项，KEY1/KEY2 减少或增加数值；时间设置用 KEY3 保存。
- SW4：进入警报；关闭 SW4 后长按 KEY4 至少 2 秒退出警报。
- SW1：正常播放静音开关。警报模式独立于正常静音设置。

## 验证与限制

本版完成 25 项仿真检查和 TD 编译，最近构建 setup/hold 余量分别为 1.388 ns / 0.011 ns。用户报告此前版本所有功能连续运行 2 小时正常，并完成 1000 次切换；此后波形细化版本尚未记录同等时长的实板复测。

LUT 使用 15942/19600，剩余 18.66%，未达到项目中 20% 的余量目标。频谱显示使用 8 个 Goertzel 频点。断电后需重新设置日期时间。
